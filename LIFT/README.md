# LIFT project page

Project page of *LIFT: Layout-In-Future Video Generation under Large Viewpoint Change via On-Policy Self-Distillation*
(Nerfies template, same layout as `../sa4d`).

- `index.html` is generated by `LIFT-CAM/camlayout/cc_workstation/video_demo_build/build_project_page.py` from
  `project_page_template.html` next to it: the "Video Results" section embeds the demo page's data (video paths,
  captions, ground-truth boxes of the conditioned objects). Edit the template, not index.html, and rerun the script.
- `static/videos/exNN_demoDD/*.mp4` are the demo page's 20 clips x 6 videos (640x352) and `ui_demo.mp4` the interface
  recording, copied from `code/video_demo/videos`.
- `static/images/*` are the paper figures rasterised from `LIFT_paper/figs/*.pdf` (teaser, data pipeline, architecture, OPSD; `thumbs/exNN.jpg` = ground-truth last frames for the carousel strip) plus `ui_poster.jpg` (a frame of the recording) and `hf-logo.svg` (huggingface_logo-noborder.svg from huggingface.co).
- `static/css`, `static/js` are copies of the site's shared Nerfies assets.
